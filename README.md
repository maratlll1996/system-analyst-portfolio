# О проекте

Данный репозиторий содержит пример аналитического кейса для финтех-сервиса оформления кредитной заявки.

В рамках проекта были подготовлены основные артефакты системного аналитика:

- бизнес-требования;
- функциональные и нефункциональные требования;
- SRS (Software Requirements Specification);
- User Story и Use Case;
- API-контракты;
- описание интеграции через RabbitMQ;
- BPMN/UML/ER-диаграммы;
- acceptance criteria;
- тест-кейсы;
- модель данных.

Проект демонстрирует базовые навыки junior системного аналитика:
- сбор и структурирование требований;
- описание REST API;
- понимание синхронных и асинхронных интеграций;
- моделирование бизнес-процессов;
- подготовка аналитической документации;
- работа с JSON и структурой данных.
