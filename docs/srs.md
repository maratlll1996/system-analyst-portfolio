# SRS: Сервис оформления кредитной заявки

## 1. Назначение системы

Система предназначена для оформления кредитной заявки, передачи данных в скоринговый сервис, получения решения и уведомления клиента о результате.

## 2. Цели проекта

- автоматизировать процесс подачи заявки;
- сократить время принятия решения;
- обеспечить интеграцию со скоринговой системой;
- обеспечить сохранение истории статусов заявки;
- передавать события в другие сервисы через RabbitMQ.

## 3. Участники процесса

| Роль | Описание |
|---|---|
| Клиент | Подает заявку на кредит |
| Application Service | Обрабатывает заявку |
| Scoring Service | Принимает решение по заявке |
| Notification Service | Уведомляет клиента |
| Analytics Service | Получает события для аналитики |

## 4. Основной сценарий

1. Клиент отправляет заявку.
2. Система валидирует данные.
3. Система создает заявку со статусом `created`.
4. Система отправляет данные в скоринговый сервис.
5. Скоринговый сервис возвращает решение.
6. Система обновляет статус заявки.
7. Система публикует событие в RabbitMQ.
8. Сервис уведомлений отправляет клиенту сообщение.

## 5. Ограничения

- обмен данными выполняется в формате JSON;
- API должно быть задокументировано через Swagger/OpenAPI;
- доступ к API выполняется только по HTTPS;
- персональные данные не должны передаваться в логах в открытом виде.

## 6. Критерии готовности

- описаны бизнес- и функциональные требования;
- подготовлен API-контракт;
- описано RabbitMQ-событие;
- подготовлены BPMN, Sequence и ER-диаграммы;
- описаны acceptance criteria и тест-кейсы.
