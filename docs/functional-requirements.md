# Functional Requirements

FR-1  
Система должна принимать POST-запрос на создание заявки.

FR-2  
Система должна валидировать обязательные поля.

FR-3  
После создания заявки система должна отправить данные в скоринг.

FR-4  
После получения результата скоринга система должна обновить статус заявки.

FR-6
Система должна предоставлять возможность получения информации о заявке по идентификатору

FR-7
Система должна предоставлять возможность получения текущего статуса заявки.

FR-8
Система должна предоставлять возможность отмены заявки.
