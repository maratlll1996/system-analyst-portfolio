# Glossary

| Термин | Описание |
|---|---|
| REST API | Способ взаимодействия систем через HTTP-запросы |
| JSON | Формат обмена данными между системами |
| RabbitMQ | Брокер сообщений для асинхронного обмена |
| Producer | Сервис, который публикует сообщение |
| Consumer | Сервис, который читает сообщение |
| Scoring | Процесс оценки клиента для принятия решения |
| Application | Кредитная заявка |
| Status | Текущее состояние заявки |
| JWT | Токен авторизации |
| SRS | Software Requirements Specification |
| BPMN | Нотация для описания бизнес-процессов |
| UML | Нотация для описания структуры и поведения системы |
