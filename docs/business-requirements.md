# Business Requirements

## Цель системы

Автоматизировать процесс подачи кредитной заявки и сократить время принятия решения.

---

# Основные бизнес-требования

| ID | Цель |
|---|---|
| BG-1 | Сократить время обработки заявки |
| BG-2 | Автоматизировать взаимодействие со скоринговой системой |
| BG-3 | Снизить количество ручных операций |
| BG-4 | Повысить удобство подачи заявки для клиента |
| BG-5 | Обеспечить прозрачность статусов заявки |
| BG-6 | Подготовить систему к масштабированию |
