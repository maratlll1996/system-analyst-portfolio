# Use Case: Создание кредитной заявки

## Название

Создание кредитной заявки клиентом.

## Основной актор

Клиент.

## Заинтересованные стороны

- клиент;
- банк;
- скоринговая система;
- сервис уведомлений.

## Предусловия

- клиент авторизован;
- клиент имеет доступ к форме подачи заявки;
- сервис заявок доступен.

## Основной сценарий

1. Клиент открывает форму подачи заявки.
2. Клиент заполняет сумму, срок и тип продукта.
3. Клиент отправляет заявку.
4. Система проверяет обязательные поля.
5. Система создает заявку.
6. Система отправляет данные в скоринговый сервис.
7. Скоринговый сервис возвращает решение.
8. Система обновляет статус заявки.
9. Система отправляет событие в RabbitMQ.
10. Клиент получает уведомление о результате.

## Альтернативные сценарии

### A1: Не заполнены обязательные поля

1. Клиент отправляет заявку без обязательного поля.
2. Система возвращает ошибку `400 Bad Request`.
3. Заявка не создается.

### A2: Скоринговый сервис недоступен

1. Система отправляет данные в скоринг.
2. Скоринговый сервис не отвечает.
3. Система переводит заявку в статус `scoring_pending`.
4. Система выполняет повторную попытку отправки.

### A3: Клиент не авторизован

1. Клиент отправляет запрос без токена.
2. Система возвращает ошибку `401 Unauthorized`.

## Постусловия

- заявка создана;
- статус заявки сохранен;
- событие опубликовано;
- клиент уведомлен.
