# Test Cases

| ID | Проверка | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-1 | Создание заявки с корректными данными | Отправить POST /applications с валидным JSON | Заявка создана, статус `created` |
| TC-2 | Создание заявки без суммы | Отправить запрос без поля `amount` | Ошибка `400 Bad Request` |
| TC-3 | Создание заявки без токена | Отправить запрос без Authorization header | Ошибка `401 Unauthorized` |
| TC-4 | Получение заявки по ID | Отправить GET /applications/{id} | Возвращается информация по заявке |
| TC-5 | Проверка публикации события | Изменить статус заявки | Событие отправлено в RabbitMQ |
| TC-6 | Недоступность скоринга | Смоделировать timeout скорингового сервиса | Заявка переходит в `scoring_pending` |
| TC-7 | Проверка истории статусов | Изменить статус заявки | В истории появляется новая запись |
