# Non-Functional Requirements

## Производительность

NFR-1  
Система должна обрабатывать запрос на создание заявки не более чем за 3 секунды.

NFR-2  
Система должна поддерживать не менее 1000 одновременных запросов.

---

## Надежность

NFR-3  
Система должна обеспечивать доступность не менее 99%.

NFR-4  
При временной недоступности скорингового сервиса запрос должен быть повторен автоматически.

---

## Безопасность

NFR-5  
Все API должны работать только по HTTPS.


NFR-6  
Персональные данные клиента должны храниться в зашифрованном виде.

---

## Масштабируемость

NFR-7  
Система должна поддерживать горизонтальное масштабирование сервисов.

NFR-8
RabbitMQ должен обеспечивать асинхронную обработку событий без потери сообщений.

---


## Поддерживаемость

NFR-12  
API должно быть задокументировано через Swagger.

NFR-13  
Система должна поддерживать обратную совместимость API между версиями.

---

## Интеграции

NFR-14  
Система должна поддерживать обмен данными в формате JSON.

NFR-15  
Интеграции между сервисами должны поддерживать retry-механизм при ошибках сети.
